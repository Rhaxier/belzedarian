# Belzedarian

the bot. lichess.org/@/Belzedarian

contact @Rhaxier at Discord

Pulls data from belzedar.duckdns.org/atomicdb (the formidable AtomicDB) for initial evaluated moves, and then runs an Atomic-Stockfish build.

Thanks to [@Wolfram_EP](https://lichess.org/@/Wolfram_EP) for providing nonterm6.txt (ask them to get a copy), which
has been converted to wolfrandom.fen here for wolfrandom position testing. However you can't use it now (kekw) cuz
lichess discriminates against custom pos for variants.
